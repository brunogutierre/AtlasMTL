# Test fixtures

Small extracts of the real open data files, with geometries replaced by a small square to keep them short. Sources (CC-BY 4.0):

- `parks.geojson`: Ville de Montréal, *Grands parcs, parcs d'arrondissements et espaces publics*
- `boroughs.geojson`: Ville de Montréal, *Limites administratives de l'agglomération de Montréal*
- `addresses.csv`: Ville de Montréal, *Adresses ponctuelles*
